#  Sistema de Média Escolar

> Aplicação web desenvolvida em React para calcular a média de alunos a partir de quatro avaliações e determinar a situação acadêmica final de forma simples e intuitiva.

Projeto desenvolvido com foco no aprendizado e consolidação dos conceitos fundamentais do **React**, como componentes, gerenciamento de estado, eventos, formulários e renderização condicional.

---

##  Sobre o Projeto

O **Sistema de Média Escolar** permite ao usuário cadastrar o nome de um aluno e suas quatro notas de avaliação (`AV1`, `AV2`, `AV3`, `AV4`). Com base nos dados inseridos, a aplicação valida as entradas, calcula a média aritmética e informa a situação acadêmica do estudante.

###  Regras de Avaliação

| Média | Situação | Status |
| :---: | :---: | :---: |
| **7,0 a 10,0** |  **Aprovado** | Sucesso |
| **5,0 a 6,9** |  **Em Recuperação** | Atenção |
| **0,0 a 4,9** | **Reprovado** | Retenção |
